Базові UI Елементи

1. Radiobutton (Перемикач)

Дозволяє обрати виключно один варіант із декількох взаємовиключних опцій.

2. Checkbox (Прапорець)

Використовується для вибору кількох незалежних опцій одночасно або підтвердження дії.

3. Text input (Текстове поле)

Поле, куди користувач може ввести однорядковий текст (ім'я, пошуковий запит тощо).

4. Tabs (Вкладки)

Групують контент за логічними розділами, дозволяючи перемикати відображення без оновлення сторінки.

Привіт! Тут відображається інформація профілю.
Тут знаходяться налаштування безпеки та приватності.

5. Button (Кнопка)

Служить для підтвердження дій, відправки даних або виклику певних функцій.

6. Text label (Мітка)

Текстовий підпис, пов'язаний з полем введення. Робить інтерфейс зрозумілішим та доступнішим.

7. Link (Посилання)

Елемент навігації для переходу між веб-сторінками або до зовнішніх ресурсів.

Перейти на GitHub →

8. Tooltip (Підказка)

Невеличке інформаційне віконце, що з'являється при наведенні курсору миші на елемент.

Наведи на це словоВау! Це прихована підказка!, щоб побачити магію.

9. Dropdown (Випадний список)

Компактний спосіб показати великий перелік опцій, з якого можна вибрати лише одну.

10. Data grid (Таблиця)

Компонент для структурованого подання інформації у форматі рядків та стовпців.
